# Orsonero Coffee — sito demo

Demo one-page per **Orsonero Coffee** (Via Paolo Lomazzo 20 e Via Giuseppe Broggi 15, Milano), in italiano e inglese e responsive per smartphone e desktop.

- **Sito live:** https://fico-azienda.github.io/orso-nero/
- Versione inglese: https://fico-azienda.github.io/orso-nero/?lang=en

Ogni push su `main` ripubblica il sito tramite GitHub Actions (workflow *Deploy sito su GitHub Pages*). Il link compare nel riepilogo di ogni esecuzione.

## Struttura
- `index.html` — pagina (testi in italiano)
- `assets/js/main.js` — traduzioni inglesi, menu mobile, animazioni
- `assets/css/styles.css` — stile
- `assets/img/` — foto reali (crediti nel footer) e loghi

## Fonti
Testi e foto da orsonerocoffee.it, Google Maps, CiboToday/MilanoToday, Mixer Planet, Artù Magazine/Ristorando, 2foodtrippers, Flawless.life, Milan Foodie Insider.
